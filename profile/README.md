# The Netherlands ME/CFS Cohort and Biobank (NMCB) Consortium

This GitHub organization is the community space for NMCB FAIR projects.

## How This Organization Is Structured

- `nmcb-fair` is the umbrella community for shared standards and collaboration.
- Each repository reflects a specific project workstream.
- Shared governance and community documentation are maintained centrally.

## Current Project Repositories

- `nmcb-overview`
- `nmcb-codebook`
- `nmcb-castor` (archived)
- `castor-eligibility`
- `acs-data-clean`
- `patient-resume`
- `sample-request`
- `data-request`

## Notes

- Most repositories are private and intended for consortium collaboration.
- Archived repositories are retained for transparency and reproducibility.
